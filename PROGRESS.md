## Where things stand

This is the `1.21.1` branch (Minecraft 1.21.1, Fabric and NeoForge). `main` is 26.2 and 26.3.

- **Done:** Pocket List 0.3.0+1.21.1 (0.2.1+1.21.1 released, 0.3.0+1.21.1 ready: Paste List, Copy List, From Litematica): the same features as 0.2.0 on 26.x. The HUD checklist, the list and settings screens, pinning with Z from inventories, the recipe book, JEI and REI, Break down, and chest memory, including used storage blocks. The Fabric game test and the NeoForge in-game test pass on their own, with JEI and with REI. CI runs all six.
- **Different on 1.21.1:** there are no shelves, so the used-storage check uses a decorated pot (whose contents reach the player's game at chunk load or from a command, not when filled by hand). Bundles are an experiment, so the tests check them on a made-up stack. Break down reads the recipes the game sends every client on 1.21.1, so it knows all of them on servers too.
- **Broken:** Nothing known.
- **Next:** Release when Gabby says so (tag `v0.3.0+1.21.1`). Changes made on `main` are ported here by hand.
