# Progress

What's done, what's broken, what's next. Newest entry first. Each session adds a row before it
ends, saying what changed, what the game test counted, what the proof run was (the feature off,
which checks fail, code put back), what was learned, and what was deliberately not done.

## Where things stand

This is the `1.20.1` branch (Minecraft 1.20.1, Fabric and Forge). `main` is 26.2 and 26.3; `1.21.1` is 1.21.1 on Fabric and NeoForge.

- **Done:** Pocket List 0.3.0+1.20.1 (0.2.0+1.20.1 released, 0.3.0+1.20.1 ready: Paste List, Copy List, From Litematica): the same features as 0.2.0 on 26.x and 0.2.0+1.21.1. The HUD checklist, the list and settings screens, pinning with Z from inventories, the recipe book, JEI and REI, Break down, and chest memory, including used storage blocks. The Fabric game test and the Forge in-game test pass on their own, with JEI and with REI. CI runs all six.
- **Different on 1.20.1:** no vanilla block holds things without a screen (no shelves; decorated pots hold only sherds), so the used-storage check stands a chiseled bookshelf in for a modded storage block. Bundles are an experiment, so the tests check them on a made-up stack. What's inside carried shulker boxes and bundles is read from NBT. Break down reads the recipes the game sends every client on 1.20.1.
- **Broken:** Nothing known here. The first-list-name bug fixed on this branch (below) is still in 0.2.0 and 0.2.0+1.21.1.
- **Next:** Release when Gabby says so (tag `v0.3.0+1.20.1`). Changes made on `main` are ported here by hand.
